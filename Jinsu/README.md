# Jinsu

개인 작업 문서를 보관하는 폴더입니다. 대분류는 `Teia/`와 같게 맞추고, 소분류는 필요할 때 만듭니다.

| 대분류 | 내용 |
|---|---|
| `00.General` | 다른 대분류에 속하지 않는 개인 활동 |
| `10.Project` | 개인 프로젝트별 산출물 |
| `20.Data` | 데이터베이스와 데이터 저장소 문서 |
| `30.Dev` | 개발 영역별 학습 자료와 가이드 |
| `80.Knowledge` | 세미나와 아티클 같은 공유 자료 |
| `90.Working` | 도구 사용 규칙과 작업 공간 자료 |

## 규칙

- 소분류는 상위 대분류와 같은 10의 자리 번호를 씁니다. 예: `20.Data/21.RDB`
- 소분류 아래 폴더에는 번호를 붙이지 않습니다.
- 회사 자료는 이 폴더에 두지 않습니다. 회사 문서는 git에 올라가지 않는 `Teia/`에만 둡니다.
