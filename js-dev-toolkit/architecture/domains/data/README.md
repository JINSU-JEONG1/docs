## 이 영역에서 다루는 것

데이터의 의미와 소유권, 저장 방식, 일관성, 이동 및 분석 구조를 다룹니다. 어떤 데이터가 어디에 존재하며 누가 변경할 수 있는지부터 정리하고, 업무 처리와 분석 목적에 맞는 흐름을 설계하는 곳입니다.

- **핵심 질문:** 데이터의 원본은 어디에 있으며, 여러 시스템에서 같은 데이터를 어떻게 신뢰할 수 있는가?
- **정리할 산출물:** 데이터 모델, 소유권 표, 저장소 구성도, 데이터 흐름도, 보존·삭제 기준입니다.

## 읽는 순서와 활용 방법

1. 모델과 소유권을 정리하여 데이터의 의미와 변경 책임을 구분합니다.
2. 조회·갱신 패턴을 기준으로 저장 방식과 트랜잭션 범위를 검토합니다.
3. 데이터 이동과 분석 구조를 설계하고, 품질·보존·삭제 기준을 함께 정리합니다.

먼저 [01 데이터 모델링과 소유권](<[draft]01-modeling-and-ownership.md>)을 읽습니다. 이어지는 주제는 현재 작성 예정이며, 다른 영역의 상세 문서는 [전체 안내의 바로 읽을 수 있는 문서](../../README.md#바로-읽을-수-있는-문서)에서 확인할 수 있습니다.
