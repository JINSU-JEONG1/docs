1. **모듈 경계** — 비즈니스 도메인 단위로 코드를 물리적으로 분리
2. **인터페이스 통신** — 모듈 간 직접 호출 금지, 공개 API(인터페이스)로만 접근

4. **단일 배포** — 모놀리스처럼 하나의 프로세스로 배포
5. **MSA 진입 전 단계** — 경계가 검증되면 서비스로 분리 가능
