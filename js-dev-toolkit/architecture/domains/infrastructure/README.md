## 이 영역에서 다루는 것

애플리케이션을 실행하고 연결하며 배포·관측·복구하는 기반을 다룹니다. 실행 환경을 고르는 데서 끝내지 않고, 장애 대응과 운영 책임, 용량 및 비용까지 연결해 설계하는 곳입니다.

- **핵심 질문:** 서비스를 어디에서 실행하고, 어떻게 배포하며, 장애가 나면 어떻게 복구할 것인가?
- **정리할 산출물:** 배포·네트워크 구성도, 환경 분리 기준, 복구 계획, 관측 항목, 용량 계획입니다.

## 읽는 순서와 활용 방법

1. 실행 대상과 운영 책임을 확인하고 컴퓨팅·호스팅, 네트워크 구성을 정합니다.
2. 환경 및 계정 구조와 플랫폼 운영 방식을 정리합니다.
3. 가용성·복구 목표를 기준으로 배포, 관측, 용량과 비용을 함께 검토합니다.

위 순서는 본문을 작성하거나 설계를 진행할 때의 순서입니다. 현재 학습 가능한 상세 문서는 [전체 안내의 바로 읽을 수 있는 문서](../../README.md#바로-읽을-수-있는-문서)에서 확인할 수 있습니다.
