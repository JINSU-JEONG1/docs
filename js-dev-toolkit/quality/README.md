# quality

코드 품질 기준, 정적 분석, 의존성 및 보안 취약점 점검 자료를 둡니다.

## 주제 폴더

| 폴더 | 다루는 개념 |
|---|---|
| [code-review](code-review/README.md) | 변경 사항의 정확성, 이해 가능성과 유지보수성을 검토하는 기준을 다룹니다. |
| [coding-standards](coding-standards/README.md) | 코드 형식, 이름과 구조에 대한 팀 규칙을 다룹니다. |
| [dependencies](dependencies/README.md) | 외부 라이브러리의 선택, 업데이트와 위험 관리를 다룹니다. |
| [security-checks](security-checks/README.md) | 코드와 구성에서 보안 문제를 찾고 대응하는 점검 개념을 다룹니다. |
| [static-analysis](static-analysis/README.md) | 코드를 실행하지 않고 잠재 오류와 규칙 위반을 찾는 방법을 다룹니다. |
