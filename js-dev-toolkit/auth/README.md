# Auth

사용자나 애플리케이션의 신원을 확인하고 접근 권한을 관리하는 영역입니다. 인증, 권한 위임, API 키를 구분해 다룹니다.

| 폴더 | 설명 |
|---|---|
| [oauth2](oauth2/) | 다른 애플리케이션에 자원 접근 권한을 위임하는 표준입니다. |
| [oidc](oidc/) | OAuth 2.0 위에 사용자 인증 기능을 더한 OpenID Connect입니다. |
| [api-keys](api-keys/) | 호출 주체를 식별하고 접근을 관리하기 위해 발급하는 키입니다. 전달·교체·폐기 방법을 함께 관리합니다. |
