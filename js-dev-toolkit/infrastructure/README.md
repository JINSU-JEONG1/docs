# Infrastructure

애플리케이션을 실행하고 배포·운영하기 위한 기반 환경입니다.

| 폴더 | 설명 |
|---|---|
| [compute](compute/README.md) | 서버와 가상 머신 등 애플리케이션을 실행하는 컴퓨팅 자원을 다룹니다. |
| [cloud](cloud/README.md) | 클라우드 계정·프로젝트와 환경의 기반 구성을 다룹니다. |
| [network](network/README.md) | DNS, TLS, 라우팅과 트래픽 분산을 다룹니다. |
| [container](container/README.md) | 애플리케이션 컨테이너의 이미지와 실행 환경을 다룹니다. |
| [storage](storage/README.md) | 파일·블록·객체 저장소 등 데이터를 보관하는 기반을 다룹니다. |
| [iac](iac/README.md) | 인프라 자원과 서버 구성을 코드로 선언하고 관리합니다. |
| [cicd](cicd/README.md) | 코드 변경의 빌드·테스트·배포 과정을 자동화합니다. |
| [gateway](gateway/README.md) | 외부 요청을 내부 서비스로 전달하고 공통 요청 정책을 적용합니다. |
| [service-mesh](service-mesh/README.md) | 서비스 간 통신에 트래픽 제어·암호화·관측 정책을 적용합니다. |
| [observability](observability/README.md) | 메트릭·로그·추적으로 시스템 상태와 문제를 파악합니다. |
| [security](security/README.md) | 인프라의 비밀정보와 접근 권한을 보호합니다. |
| [database](database/README.md) | 데이터베이스 연결과 접속 기반을 다룹니다. |
| [messaging](messaging/README.md) | 서비스 간 비동기 메시지 전달 기반을 다룹니다. |
| [backup-recovery](backup-recovery/README.md) | 백업과 장애 복구를 준비하고 복원 가능성을 확인합니다. |
| [cost](cost/README.md) | 인프라 자원의 사용량과 비용을 파악하고 관리합니다. |

설계 참고: [MSA 인프라 구성 설계안](<cloud/[draft]msa-infrastructure-plan.md>) · [인프라 아키텍처](../architecture/infrastructure/README.md)
