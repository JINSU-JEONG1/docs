# testing

단위·통합·시스템 테스트의 전략과 실행 자료를 둡니다. 재사용 문서 양식은 templates/testing에 둡니다.

## 주제 폴더

| 폴더 | 다루는 개념 |
|---|---|
| [end-to-end](end-to-end/README.md) | 사용자 관점의 전체 기능 흐름을 검증합니다. |
| [integration](integration/README.md) | 모듈과 외부 구성요소의 연결 동작을 함께 검증합니다. |
| [performance](performance/README.md) | 처리량, 응답 시간과 부하 한계를 검증합니다. |
| [strategy](strategy/README.md) | 위험과 변경 범위에 맞춰 테스트 수준과 우선순위를 정하는 개념을 다룹니다. |
| [test-data](test-data/README.md) | 재현 가능하고 격리된 테스트 데이터를 준비·정리하는 방법을 다룹니다. |
| [unit](unit/README.md) | 작은 코드 단위를 외부 의존성과 분리해 검증하는 방법을 다룹니다. |
