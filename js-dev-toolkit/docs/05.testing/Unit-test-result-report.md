## 3. 단위 테스트 케이스 명세 및 결과

### 3.1 [모듈명 예시] 회원 인증 (AuthService)

> **관련 요구사항:** REQ-AUT-001, REQ-AUT-002

| TC ID | 테스트 대상 함수 | 테스트 조건 (Given) | 입력값 (When) | 기대 결과 (Then) | 결과 | 비고 |
|---|---|---|---|---|---|---|
| UT-AUT-001 | `verifyKakaoToken()` | 유효한 카카오 토큰이 전달된 경우 | `token = "valid_kakao_token"` | 사용자 정보 객체 반환 | ✅ PASS | |
| UT-AUT-002 | `verifyKakaoToken()` | 만료된 토큰이 전달된 경우 | `token = "expired_token"` | `UnauthorizedException` 발생 | ✅ PASS | |
| UT-AUT-003 | `verifyKakaoToken()` | null 값이 전달된 경우 | `token = null` | `IllegalArgumentException` 발생 | ✅ PASS | |
| UT-AUT-004 | `registerOrLogin()` | 신규 회원 토큰인 경우 | `kakaoId = "new_user_001"` | 신규 회원 저장 후 JWT 반환 | ✅ PASS | |
| UT-AUT-005 | `registerOrLogin()` | 기존 회원 토큰인 경우 | `kakaoId = "existing_user_001"` | 기존 회원 조회 후 JWT 반환 | ❌ FAIL | 6절 참조 |
| UT-AUT-006 | `disableBiometric()` | 생체 인증이 활성화된 회원인 경우 | `memberId = "user_001"` | 생체 인증 플래그 N으로 변경 | ✅ PASS | |

### 3.2 [모듈명 예시] 주문 처리 (OrderService)

> **관련 요구사항:** REQ-ORD-001

| TC ID | 테스트 대상 함수 | 테스트 조건 (Given) | 입력값 (When) | 기대 결과 (Then) | 결과 | 비고 |
|---|---|---|---|---|---|---|
| UT-ORD-001 | `calculateOrderAmount()` | 정상 상품 2종 선택 | `items = [{id:1, qty:2}, {id:2, qty:1}]` | 상품 합계 + 배송비 = 35,000원 | ✅ PASS | |
| UT-ORD-002 | `calculateOrderAmount()` | 빈 상품 목록 전달 | `items = []` | `IllegalArgumentException` 발생 | ✅ PASS | |
| UT-ORD-003 | `validateStock()` | 주문 수량이 재고보다 적은 경우 | `orderQty=2, stock=5` | `true` 반환 | ✅ PASS | |
| UT-ORD-004 | `validateStock()` | 주문 수량이 재고보다 많은 경우 | `orderQty=6, stock=5` | `OutOfStockException` 발생 | ✅ PASS | |
| UT-ORD-005 | `validateStock()` | 재고가 0인 경우 | `orderQty=1, stock=0` | `OutOfStockException` 발생 | ✅ PASS | |
