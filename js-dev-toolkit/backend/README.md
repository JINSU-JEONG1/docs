# backend

서버 애플리케이션과 업무 기능의 구현 자료를 둡니다.

## 주제 폴더

| 폴더 | 다루는 개념 |
|---|---|
| [application-structure](application-structure/README.md) | 서버 코드의 구성 단위와 의존성 경계를 다룹니다. |
| [background-processing](background-processing/README.md) | 요청 처리와 분리된 비동기 작업과 스케줄 처리를 다룹니다. |
| [business-logic](business-logic/README.md) | 업무 규칙과 유효성, 처리 결과를 코드로 표현하는 개념을 다룹니다. |
| [caching](caching/README.md) | 반복 조회 결과를 재사용해 처리량과 응답 시간을 개선하는 개념을 다룹니다. |
| [configuration](configuration/README.md) | 환경별 설정과 민감정보를 애플리케이션에 전달하는 방식을 다룹니다. |
| [error-handling](error-handling/README.md) | 오류 분류, 전파와 일관된 응답 처리를 다룹니다. |
| [request-processing](request-processing/README.md) | 요청 수신부터 응답 반환까지 서버 처리 흐름을 다룹니다. |
