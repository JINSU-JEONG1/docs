# frontend

웹 화면과 클라이언트 애플리케이션의 구현 자료를 둡니다.

## 주제 폴더

| 폴더 | 다루는 개념 |
|---|---|
| [design-system](design-system/README.md) | 디자인 토큰, 공통 UI 컴포넌트와 사용 규칙을 다룹니다. |
| [accessibility](accessibility/README.md) | 다양한 사용자가 화면과 기능에 접근할 수 있도록 하는 원칙을 다룹니다. |
| [forms-and-validation](forms-and-validation/README.md) | 사용자 입력, 검증과 제출 흐름을 다룹니다. |
| [performance](performance/README.md) | 화면 로딩과 상호작용 성능을 측정하고 개선하는 개념을 다룹니다. |
| [routing](routing/README.md) | 화면 간 이동, URL과 탐색 상태를 구성하는 개념을 다룹니다. |
| [state-and-data-flow](state-and-data-flow/README.md) | 화면 상태와 데이터 흐름을 관리하는 개념을 다룹니다. |
| [ui-structure](ui-structure/README.md) | 화면과 컴포넌트의 코드 구조와 책임 분리를 다룹니다. |
| [web-platform](web-platform/README.md) | 브라우저와 웹 표준, 문서 구조와 스타일, 기본 실행 환경을 다룹니다. |
