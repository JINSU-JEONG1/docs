# operations

배포 후 서비스 운영, 장애 대응, 유지보수와 운영 절차 자료를 둡니다. 인프라 자원과 배포 기반은 infrastructure에서 다룹니다.

## 주제 폴더

| 폴더 | 다루는 개념 |
|---|---|
| [environments-and-configuration](environments-and-configuration/README.md) | 개발·검증·운영 환경과 설정 차이를 관리하는 개념을 다룹니다. |
| [incident-response](incident-response/README.md) | 장애를 감지·분류하고 복구 및 후속 조치를 진행하는 방법을 다룹니다. |
| [maintenance](maintenance/README.md) | 정기 점검, 패치와 수명 종료에 따른 유지보수를 다룹니다. |
| [monitoring-and-alerting](monitoring-and-alerting/README.md) | 서비스 상태를 확인하고 대응이 필요한 변화를 알리는 방법을 다룹니다. |
| [release-and-rollback](release-and-rollback/README.md) | 변경을 배포하고 문제가 생겼을 때 안전하게 되돌리는 절차를 다룹니다. |
